# SOLOIST product agent

Агент раз в минуту:

1. читает новые товарные посты из настроенных Telegram-каналов;
2. отбрасывает повторы в SQLite;
3. нормализует название и категорию через AI или локальные правила;
4. рассчитывает обе цены и собирает пост в формате `@soloist_store`;
5. присылает владельцу Telegram-бота только фото и готовый текст поста.

Бот ничего не публикует в канал автоматически. Внутренняя очередь сохраняется в базе, но её номера, расчёты и служебные подписи пользователю не отправляются.

## 0. Сначала замени токен

Токен, отправленный в чат, уже нельзя считать секретным. В `@BotFather` выбери бота, выполни отзыв текущего токена (`/revoke`) и создай новый. Старый токен не используй и не добавляй в файлы проекта.

## 1. Локальный запуск

```bash
cd automation
python3 -m venv .venv
source .venv/bin/activate
cp .env.example .env
```

Запиши новый токен в `.env`, оставь `TELEGRAM_ADMIN_ID=0` и запусти:

```bash
./soloist-agent run
```

Напиши боту `/whoami`. Он вернет числовой Telegram ID. Останови агент, внеси ID в `.env` и запусти снова. Это не дает постороннему пользователю управлять очередью.

Проверка конфигурации:

```bash
./soloist-agent doctor
```

Однократный сбор без отправки в Telegram:

```bash
./soloist-agent scan
./soloist-agent list
./soloist-agent preview 1
```

## 2. Расчет цен

Для Taobao/Pinduoduo:

```text
закупка = цена_CNY × 13 × 1.15
итог = закупка + доставка + наценка
```

| Категория | Доставка | Наценка |
|---|---:|---:|
| Футболка | 500–600 ₽ | 1 000 ₽ |
| Лонгслив | 800 ₽ | 1 300 ₽ |
| Кофта/джинсы | 1 000 ₽ | 1 600 ₽ |
| Куртка | 1 200 ₽ | 2 000 ₽ |
| Обувь | 1 500 ₽ | 2 200 ₽ |
| Супертяжелая обувь | 2 000 ₽ | 2 500 ₽ |

Для Telegram-каналов цена источника уменьшается на 500 ₽. Если после такого вычитания цена была бы не выше 3 000 ₽, скидка уменьшается до стабильных для товара 200 или 300 ₽, чтобы не съедать маржу. Цены Telegram-источников уже оформлены как розничные, поэтому эта разница сохраняется точно. Для маркетплейсов результат округляется вверх до цены, оканчивающейся на `490` или `990`: например, `2342 → 2490`.

Старая цена детерминированно генерируется для скидки от 25% до 70%. Для одного и того же товара она не прыгает при повторном запуске.

Проверить формулу можно без сети:

```bash
./soloist-agent price 55 tshirt
./soloist-agent price 5490 jeans --source telegram
```

Все коэффициенты находятся в `.env` и меняются без правки кода.

## 3. Telegram-источники

Каналы задаются через запятую:

```text
TELEGRAM_SOURCE_CHANNELS=destiny_place,ikarushop
TAOBAO_BROWSER_ENABLED=false
```

Для чтения истории канал должен отдавать публичную страницу `https://t.me/s/<channel>`. Если владелец канала отключил публичный просмотр сообщений, одного username недостаточно: нужно добавить бота в канал либо передать доступный публичный источник.

## 4. AI-слой

`OPENAI_API_KEY` необязателен. С ключом агент переводит китайские названия, проверяет соответствие dark/archive-тематике, выделяет бренд и определяет весовую категорию. Без ключа он использует найденный поисковый запрос и словари категорий.

AI не получает токен Telegram. Секреты читаются только из `.env`, который исключен из Git и Docker-контекста.

## 5. Docker/VPS

```bash
cd automation
cp .env.example .env
# заполнить .env
docker compose up -d --build
docker compose logs -f
```

База хранится в `automation/data/soloist_agent.sqlite3`. Каталог подключается как volume и не пропадает после пересборки контейнера.

## Команды бота

- `/scan` — собрать товары сейчас;
- `/queue` — статистика очереди;
- `/pending` — повторно показать ожидающие посты;
- `/whoami` — показать Telegram ID;
- `/help` — справка.

Используй только изображения и описания, на которые у магазина есть права. Сгенерированную «старую» цену и заявления о соответствии оригиналу стоит отдельно проверить на соответствие правилам рекламы и защиты потребителей в странах продаж.
